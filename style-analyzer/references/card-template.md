# Style DNA Card Template

Copy this template when producing a Style DNA Card. Replace bracketed placeholders.

```markdown
# Style DNA Card: [Paper ID]

## Relevance
| Field | Method | Journal | Verdict |
|-------|--------|---------|---------|
| [same/adjacent/different] | [same/adjacent/different] | [top/field/lower] | [✅/⚠️/❌] [one-line reason] |

## Sentence DNA
[3-5 sentence paragraph. Include: avg length, variation pattern, opening/closing habits, one-sentence summary.]

## Paragraph DNA
[3-5 sentence paragraph. Include: opening type %, closing type %, length, internal structure, citation placement, one-sentence summary.]

## Voice
[2-3 sentence paragraph. Include: pronoun choice, certainty level, hedging density.]

## Lexical Snapshot
| Metric | Finding |
|--------|---------|
| Register | [high / medium / low] |
| Abstract:Concrete | [X:Y ratio] |
| Verb style | [action / stative / mixed] |
| Adjective use | [restrained / moderate / abundant] |
| Jargon density | [N terms per paragraph] |

## ✂️ Stealable Patterns
1. **[Name]**: [fill-in-the-blank template] *(Section: [where])*
2. **[Name]**: [fill-in-the-blank template] *(Section: [where])*
...

---
Analyzed: [date]
Samples: [N] sentences, [N] paragraphs from Introduction + Discussion
```
