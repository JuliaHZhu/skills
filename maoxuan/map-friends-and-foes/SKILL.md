# 分清敌友：行动前的阵营测绘 (map-friends-and-foes)

## R — 原文 (Reading)

> 谁是我们的敌人？谁是我们的朋友？这个问题是革命的首要问题。中国过去一切革命斗争成效甚少，
> 其基本原因就是因为不能团结真正的朋友，以攻击真正的敌人。
>
> — 毛泽东，《中国社会各阶级的分析》（1925）

> 那动摇不定的中产阶级，其右翼可能是我们的敌人，其左翼可能是我们的朋友——但我们要时常提防他们，
> 不要让他们扰乱了我们的阵线。
>
> — 同上

---

## I — 方法论骨架 (Interpretation)

在动手想"怎么赢"之前，先回答"谁和我站一边、谁是我能争取的力量"。方法：

1. 把所有相关方沿**两轴**定位：
   - **利益位置**（客观）：资源、地位、与我的利害是同向还是反向；
   - **态度**（主观）：支持 / 中立 / 反对，以及可争取程度。
2. 划出**三区**：可靠盟友 / 明确对手 / 中间动摇派。

精髓在**中间派**：他们不是"友或敌"二选一，而是"可能变友也可能变敌"。要单独拎出来，
再切成"可争取的左翼"与"须提防的右翼"，分别配策略。

关键态度：这是**盘点，不是判决**——分类服务于你的资源分配（团结谁、争取谁、提防谁），
不是给谁定性、贴标签。分类结果必须靠真实行为持续验证，而不是"成分一判终身"。

## A1 — 书中的应用 (Past Application)

### 案例：1925 年大革命初期，找同盟军

- **问题**: 党内两种倾向都"感觉力量不足，却不知到哪里找力量"——陈独秀（右倾）只跟国民党合作、
  忘了农民；张国焘（"左"倾）只搞工人运动、也忘了农民。
- **方法论的使用**: 毛按经济地位 + 对革命的态度，把社会各阶级逐一分类，判定谁是敌人、谁是朋友。
- **结论**: 工业无产阶级是领导力量；农民（半无产阶级 + 小资产阶级）是最广大最忠实的同盟军；
  买办、地主、军阀及附庸是敌人；民族资产阶级是**动摇的中间派**——左翼可争取、右翼须提防。
- **结果**: 解决了"同盟军是谁"这个首要问题；"1927 年事变"验证了动摇派右翼会倒向敌人的预判。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 要进一个新市场 / 新领域，感觉"玩家很多，但分不清谁是对手、谁可以合作"。
2. 要推动一次变革或争取一个机会，感觉"支持者不够，不知道还能拉拢谁"。
3. 进入一个新学术领域或组织，想搞清楚哪些派系/学者是同盟、哪些是潜在反对者、哪些是可争取的中立者。

### 语言信号 (用户的话里出现这些就应激活)

- "我力量不够 / 不知道靠谁"
- "谁是朋友谁是敌人 / 该团结谁、防着谁"
- "这里面的玩家都有谁，谁站哪边"
- "想争取一批人，但不知道哪些拉得动"

### 与相邻 skill 的区分

- 与通用 stakeholder analysis（利益相关方分析）的区别：本 skill **强制第三区"中间动摇派"**，
  且**强制行为验证修正**，明确反对"标签一判终身"。
- 与「调查研究」（《反对本本主义》可蒸馏）的区别：调查研究是"怎么把事实搞清楚"，
  本 skill 是"事实清楚之后，怎么据此定位阵营、分配资源"。

## E — 可执行步骤 (Execution)

1. **列清单**：穷尽列出所有相关方（人 / 组织 / 派系），不漏掉沉默的多数。
   - 完成标准: 清单覆盖直接对手、潜在盟友、以及"看似无关但受影响"的一方。

2. **两轴打分**：每个相关方，标注「利益位置（同向/反向/复杂）× 态度（支持/中立/反对 + 可争取度）」。
   - 完成标准: 每个相关方都有两个维度的明确判断，且有可观测依据。

3. **划三区**：可靠盟友 / 明确对手 / 中间动摇派。
   - 完成标准: 三区无遗漏、无重叠。

4. **切中间派**：把中间动摇派再切成"左翼（可争取）"与"右翼（须提防）"，各配一条策略。
   - 完成标准: 对每个中间派成员，能说清"争取它要付出什么、提防它要盯住什么信号"。

5. **行为验证（强制）**：对每个分类，找该方**最近 1–2 个实际行为/表态**验证，不符就修正。
   - 判停条件: 若无法取得任何行为信号 → 该方应降级为"未知"，不要硬塞进某区（回到步骤 2）。

6. **定资源分配**：明确团结谁、争取谁、提防谁，以及每个"争取对象"需要投入什么。
   - 完成标准: 输出一份"对象 → 策略 → 资源"的对照清单。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 利益结构模糊、**无法用任何可观测主维度近似立场**时——此时"测绘"会失真。
- 态度高度策略化/伪装、行为信号不可得时——测不出真实立场。
- 目的只是想给人"贴标签 / 定性 / 划分敌我"时——本 skill 是**资源盘点工具**，不是道德或政治判决。

### 作者在书中警告的失败模式

- 陈独秀 / 张国焘：只盯着眼前最显眼的一方（国民党 or 工人），漏掉了沉默的多数（农民），
  结果找不到真正的同盟军。对应失败模式：**只扫显眼者、漏掉沉默多数**。

### 作者的盲点 / 时代局限

- **阶级决定论**：毛用"经济地位 → 政治态度"当锚，这正是苏联式批评所指——经济还原论、
  忽视民族/文化/个人能动性，实践里堕落成"出身论""按成分清洗"。
  本 skill 用第 5 步"行为验证"和"两轴仅是粗筛"来对冲，但使用者必须记住：
  **分类是启发式（heuristic），不是对任何个体的终审。**

### 容易混淆的邻近方法论

- SWOT / 五力 / PEST 等静态环境扫描框架：那些是"看环境"，本 skill 是"结盟动员前的力量盘点"，
  且带"争取/提防"的动作指向。
