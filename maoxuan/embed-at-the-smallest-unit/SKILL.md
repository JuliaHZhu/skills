# 组织下沉：把基因埋进最小作战单元 (embed-at-the-smallest-unit)

## R — 原文 (Reading)

> 红军所以艰难奋战而不溃散，"支部建在连上"是一个重要原因。
>
> — 毛泽东，《井冈山的斗争》（1928）

> 党代表制度，经验证明不能废除。特别是在连一级，因党的支部建设在连上，党代表更为重要。
> 他要督促士兵委员会进行政治训练，指导民运工作，同时要担任党的支部书记。
>
> — 同上

> 事实证明，哪一个连的党代表较好，哪一个连就较健全，而连长在政治上却不易有这样大的作用。
>
> — 同上

> 两年前，我们在国民党军中的组织，完全没有抓住士兵，即在叶挺部也还是每团只有一个支部，
> 故经不起严重的考验。
>
> — 同上

---

## I — 方法论骨架 (Interpretation)

组织的价值观/文化/纪律，如果只挂在总部（高层），是经不起考验的——压力一来，最先涣散的是**一线**。
毛的做法是把组织基因**下沉到最小作战单元**：在每个"连"（最小一线单位）里安一个支部、一个党代表。

拆解这个动作的三个要点：

1. **下沉到最小单元，不是停在中间层**。国民党军在叶挺部"每团只有一个支部"——支部停在团一级，
   抓不住士兵，所以"经不起严重的考验"。组织基因要落到**真正执行、真正接敌的那个最小单位**。
2. **放的是"价值观守护者"，不是"业务监工"**。党代表负责政治训练、凝聚士兵、守护价值观，
   **连长**负责作战指挥——两个角色分工明确。下沉的不是一个督战的人，而是一个
   "让这个最小单元在压力下不散"的角色。
3. **守护者必须有实权、有成效可见**。"哪一个连的党代表较好，哪一个连就较健全"——
   这个角色不是虚职，它的好坏直接决定最小单元的凝聚力和战斗力。

一句话：**价值观如果到不了最小作战单元，就只是墙上的字；到得了，才扛得住压力。**

## A1 — 书中的应用 (Past Application)

### 案例：支部建在连上 vs 每团一个支部（正反对比）

- **问题**: 1928 年井冈山，红军物质菲薄、战斗频繁、伤亡巨大，靠什么"艰难奋战而不溃散"？
- **方法论的使用**: 党的组织分连支部、营委、团委、军委四级，"连有支部，班有小组"。
  党代表（连一级）负责政治训练 + 凝聚士兵 + 任支部书记。
- **结论**: "支部建在连上"是红军不溃散的重要原因；而对比之下，两年前在国民党军（叶挺部）
  "每团只有一个支部"，组织抓不住士兵，经不起严重考验。
- **反例佐证**: 第二十八团在湘南曾取消党代表，后来发现不行，又恢复了——证明这个"最小单元的
  价值观守护者"删不得。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 组织从几个人长到几十上百人，价值观/文化开始稀释，一线执行走样。
2. 想确保"公司的理念真正落到一线"，而不是只挂在墙上、贴在入职手册里。
3. 团队在压力下容易涣散、人心散，想找"怎么让最小的作战单元也有自己的凝聚力/纪律"。

### 语言信号 (用户的话里出现这些就应激活)

- "价值观怎么落到一线，而不是挂在墙上"
- "公司大了，文化稀释了，怎么守住"
- "怎么让最小的团队/小组也有凝聚力和纪律"
- "一线的人为什么老是走样"

### 与相邻 skill 的区分

- 与「企业文化落地 / 价值观宣贯」的区别：那些是**宣传与培训**（发传单、办会、贴海报），
  本 skill 是**组织结构上安一个实权角色**（支部建在连上，不是发传单）。
- 与「non-material-motivation 非物质激励」的区别：那个解决"用什么杠杆（平等参与透明）激发个体"，
  本 skill 解决"怎么把组织基因下沉到最小单元"。两者常组合：基因下沉 + 平等参与，一起维持战斗力。

## E — 可执行步骤 (Execution)

1. **确定最小作战单元**：你的组织里，"真正执行、真正接敌"的最小单位是什么（小组/小队/团队）？
   判停：能说清"哪个层级是压力最先打到的地方"。
2. **在最小单元里设一个"价值观守护者"**：不一定是管理者（对应"党代表"≠"连长"），
   可以是文化代表/政委/老员工。判停：这个角色的职责边界清晰——"守护价值观+凝聚人"，不替代业务负责人。
3. **明确他的抓手**：他靠什么"守住价值观"？（对应党代表的"政治训练 + 士兵委员会 + 任支部书记"）。
   判停：能列出 2-3 个具体动作（如新人带教、定期对齐、在关键决策时提醒价值观）。
4. **验证"不溃散"**：在压力/冲突/关键考验场景下，观察最小单元是否还保持凝聚力与纪律。
   判停：能举出一个"有守护者的单元挺住了、没有的散了"的对比案例。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **组织还极小**（还没有"最小单元 vs 总部"之分，一个人就能盯过来）时——此时下沉是过度设计。
- **追求极致灵活、不强调纪律的创意型组织**（如小型独立工作室、临时项目组）时——
  安"价值观守护者"会拖慢节奏、制造双轨权力摩擦。
- 只是想"做一次价值观培训/宣贯"时——本 skill 要求的是**结构上的常设角色**，不是一次性动作。

### 作者在书中警告的失败模式

- **支部停在中间层（每团一个支部）**：组织抓不住士兵，经不起严重考验。对应失败模式：
  **价值观下沉到一半（停在管理层）就以为到位了，一线仍然涣散**。

### 作者的盲点 / 时代局限

- **"党代表 vs 连长"的双轨制在知识密集型组织里可能造成权力冲突**：业务负责人（连长）和
  价值观负责人（党代表）意见不一致时，谁听谁的？毛的语境靠"党指挥枪"统一了答案，
  但现代组织没有这个前提，双轨制容易内耗。
- **过度下沉会官僚化、僵化**：每个最小单元都安一个"政委"，会拖慢决策、增加层级感。
  本 skill 的下沉是"埋一个守护价值观的角色"，不是"层层加一个审批岗"。

### 容易混淆的邻近方法论

- "价值观考核 / OKR 文化指标"：那是**事后度量**，本 skill 是**事前埋角色**（结构性保障）。
  两者可互补：先下沉角色，再用指标度量成效。
