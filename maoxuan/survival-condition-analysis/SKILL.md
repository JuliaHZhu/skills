# 生存条件分析：弱者能不能活 (survival-condition-analysis)

## R — 原文 (Reading)

> 因为有了白色政权间的长期的分裂和战争，便给了一种条件，使一小块或若干小块的共产党领导的
> 红色区域，能够在四围白色政权包围的中间发生和坚持下来。
>
> — 毛泽东，《中国的红色政权为什么能够存在？》（1928）

> 我们只须知道中国白色政权的分裂和战争是继续不断的，则红色政权的发生、存在并且日益发展，
> 便是无疑的了。
>
> — 同上

> 八月失败，完全在于一部分同志不明了当时正是统治阶级暂时稳定的时候，反而采取统治阶级政治
> 破裂时候的战略，分兵冒进，致边界和湘南同归失败。
>
> — 同上

> 在统治阶级政权暂时稳定的时期和破裂的时期，割据地区对四围统治阶级必须采取不同的战略。
> 破裂时期可以比较地冒进；稳定时期则必须逐渐地推进，军事上最忌分兵冒进。
>
> — 毛泽东，《井冈山的斗争》（1928）

## I — 方法论骨架 (Interpretation)

判断"一个脆弱的新东西能不能活"，多数人先问"我够不够强、资源足不足、有没有信心"。毛反着来：
**先问"对手内部的矛盾给了我什么夹缝"，再问"我自身有没有最低限度的硬条件"**。

拆成三层，按顺序：

1. **找深层矛盾，不是看表层互撕**。表层（对手们互掐）只是投影，深层（谁在背后瓜分利益、路线/地缘/
   资本的分裂）才是持久的空间来源。毛的原话："各派军阀的矛盾和斗争，反映着帝国主义各国的矛盾和斗争"。
2. **定位你的夹缝**。你活着的空间，是**哪个分裂**给的？答不上来，就是没位置。
   —— 这是必要条件，但还不够。
3. **列自身最低硬条件**。夹缝之外，你至少得有：群众基础（有人跟你）、大势（整体向前）、
   核心实力（有真家伙）、策略正确（打法对）。

最后一条是**动态性**（八月失败的教训）：生存条件**不是静态的**。对手会从"分裂"转入"暂时稳定"，
条件一变，策略必须跟着变——把"稳定期"误判成"破裂期"、沿用扩张打法，就是死法。

一句话：**弱者能不能活 = 外部夹缝（对手分裂给的）× 自身最低硬条件 × 条件状态判断准确。**

## A1 — 书中的应用 (Past Application)

### 案例 1：红色政权为什么能在白色包围里存在（正例）

- **问题**: 1927 大革命失败后，根据地被国民党新军阀四面包围，党内普遍悲观，怀疑"红旗打得多久"。
- **方法论的使用**: 毛不回答"我们多有信心"，而是列五个生存条件：① 白色政权间的分裂战争（夹缝）
  ② 群众基础 ③ 全国形势向前 ④ 相当力量的正式红军 ⑤ 政策正确。
- **结论**: 只要"白色政权的分裂和战争继续不断"，红色政权"发生、存在并且日益发展便是无疑的"。

### 案例 2：八月失败（反例）

- **问题**: 湘赣边界 1928 年八月失败，边界和湘南同归失败。
- **方法论的使用**: 一部分同志误判了条件状态——当时正是"统治阶级暂时稳定"（夹缝收窄），
  却沿用"政治破裂时期"的分兵冒进战略。
- **结论**: 不是实力不够，是**条件状态判断错了，策略没跟着切**。九月纠正后即挽救过来。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 要做一个新项目 / 新业务 / 创业，心里没底，想判断"这玩意儿到底能不能活下来"。
2. 在巨头林立的赛道里，想搞清楚"我的生存空间到底在哪、有没有空间"。
3. 发现环境变了（融资收紧、巨头下场、政策转向），拿不准"该继续扩张还是收缩"。

### 语言信号 (用户的话里出现这些就应激活)

- "这个新东西能不能活 / 有没有戏 / 能不能做成"
- "巨头都下场了，我们还有没有空间"
- "现在环境变了，我该激进还是保守"
- "我的对手是谁，他乱不乱，乱在哪"

### 与相邻 skill 的区分

- 与 SWOT/五力/PEST 等**静态环境扫描**的区别：那些是"把环境看全"，本 skill 是"从对手矛盾里
  定位你的生存空间"，且**强制做条件状态的动态判断**（宽松/收紧两套打法）。
- 与「分清敌友 map-friends-and-foes」的区别：那是"结盟前的力量盘点（谁敌谁友）"，
  本 skill 是"判断能不能活（生存条件）"。顺序上**先做本 skill（能不能活），再做 map-friends-and-foes（怎么结盟）**。

## E — 可执行步骤 (Execution)

1. **挖深层矛盾**：列出表层可见的竞争/冲突，逐个追问"它背后是什么分裂在驱动"（路线/算力/资本/
   地缘/利益分配）。判停：能说出"深层矛盾 X 是持久的，不是临时的"。
2. **定位夹缝**：回答"我的生存空间是哪个分裂给的"。判停：一句话能说清"对手的内部分裂给我留了 X 空间"。
   —— 若答不上来，说明没有位置，不要硬启动。
3. **列自身硬条件**：逐条对照最低限度——群众基础（有没有人跟你）/ 大势（整体向前还是收缩）/
   核心实力（有没有真壁垒）/ 策略（打法对不对）。判停：四条各有可观测依据，缺哪条标哪条。
4. **判断条件状态**：当前对手处于"分裂/宽松期"还是"稳定/收紧期"？判停：给出判断 + 一个可观测信号
   （什么变了就说明状态切换了）。
5. **配策略**：**策略必须和状态绑定**，状态一变策略就切。两期的具体打法（第4篇《井冈山的斗争》细化）：

   | 条件状态 | 打法 | 红线 |
   |---|---|---|
   | **破裂期（宽松）** | 战略可比较**冒进**，扩张可比较广大 | 仍须建立**中心区域坚实基础**（基本盘），以备形势反转 |
   | **稳定期（收紧）** | 战略必须**逐渐推进**，不冒进 | 军事上**最忌分兵冒进**（集中兵力）；地方工作上**最忌人力四散**；同样注意建立基本盘 |

   判停：输出"当前状态 → 对应策略 → 切换信号"三列对照表。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **创造全新市场**（无存量对手可撕裂）时——本框架是"从现有对手手里抢空间"的零和视角，
  不适用于"新需求凭空造出新市场"的增量场景。
- **对手内部没有可观测的分裂**、或你完全无法感知对手的博弈状态时——"找夹缝"无从谈起。
- 只是想给自己打气、要一句"坚持下去就会成功"时——本 skill 给的是**冷判断**，不是鸡汤。

### 作者在书中警告的失败模式

- **八月失败**：把"暂时稳定"误判成"政治破裂"，条件变了策略没切。对应失败模式：
  **静态地看待生存环境，以为夹缝永远存在**。

### 作者的盲点 / 时代局限

- **"依附分裂"的隐含假设**：毛的框架默认"你必须依附于某个更大的分裂结构（对手内讧）才能活"。
  它忽略了两种可能：① 你自己**制造**分裂（主动挑动对手内部矛盾，或技术代差直接改写规则）；
  ② 生存空间来自**网络效应 / 新范式**而非对手失误。使用时别把"找夹缝"当成唯一路径。

### 容易混淆的邻近方法论

- 波特五力：那是"行业结构吸引力"的静态评估，本 skill 是"你这个脆弱主体能不能活"的动态诊断，
  且把"对手矛盾"提到第一优先级。
